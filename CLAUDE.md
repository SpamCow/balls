# Bumper Balls

Before doing anything in this repo, read `SETUP_GUIDE_FOR_AI.md`. It explains how the game works, how to host it (Render, a VPS or cPanel), how to set up paid play, and how to run it day to day.

Do every step you can yourself: run the commands, edit the files, build, deploy and check your own work. Involve the owner only for things that need their accounts, money or decisions, and ask for all of it in one message. Never ask for a private key or seed phrase, and never change `SERVER_SECRET` once it is set.
