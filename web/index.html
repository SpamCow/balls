How it's kept fair

  • The game server runs the physics. Your browser only sends which way you're steering, so nobody can cheat by editing the game.
  • Entry fees sit in the contract, not with us. It only pays a winner who was actually in the match, using a result signed by the game server for that exact match.
  • If a match doesn't fill in 10 minutes, or isn't settled in 30, every player can take their entry back themselves. No one can block that.
  • You can leave a match and get your entry back any time before it fills.
